# 玩法系统设计（对标《歧路旅人》）

> 状态：v0.1 已确认（回合制方案于 2026-08-31 定案）。

## 表现层：HD-2D

像素角色 + 高分辨率场景 + 现代光影 = 歧路旅人的标志观感。Godot 实现路径：

| 效果 | Godot 4.7 实现 |
| ---- | ---- |
| 像素角色/场景混排 | 角色精灵用像素过滤（Nearest），场景用高分辨率绘制 |
| 景深与视差 | 多层视差背景 + `TileMapLayer` 分层 + Y-sort |
| 氛围光照 | `CanvasModulate` 全局色调 + `PointLight2D`（路灯、法术光效） |
| 泛光/辉光 | `WorldEnvironment` glow（克制使用，夜景与法术才开） |
| 分辨率 | 1920x1080 窗口，像素角色按 3x 整数缩放 |

## 探索层

- **自由移动 + Y 排序**（WASD/方向键，已配好输入映射）
- **城镇 = 安全区**：无遇敌，NPC 对话、商店、旅店（恢复+存档）、支线（NPC 头顶图标，歧路旅人式）
- **荒野 = 危险区**：
  - **暗雷随机遇敌** + 区域危险度分级（区域越深，妖魔等级越高）
  - **明雷头目**：地图上可见的精英妖魔，打赢给稀有奖励
- **地图技能（Path Actions）**：队伍成员各有一个探索技能（见 characters.md），用于解锁支线、通路、情报——这是歧路旅人探索乐趣的直接移植
- **章节触发**：每章内设若干**剧情触发点**（进入特定区域/完成前置事件后演出）；章节间用世界地图衔接

## 战斗系统（核心，歧路旅人三大支柱的映射）

回合制指令战斗，最多 4 人，按速度决定行动顺序。

### 1. 星辰增幅（对标 BP 增幅）

原著中施法是"星子连线"——游戏中每回合行动者获得 1 点**星辉**（可存至 3 点），出招时消耗星辉增幅：

| 消耗 | 效果 |
| ---- | ---- |
| 0 | 普通施法 |
| 1~3 | 星子连线加长：威力提升 / 攻击段数增加 / 附加效果强化 |

> 主题咬合：增幅在视觉上就是"更多星子连成星轨"，法术演出天然分档。

### 2. 魔盾与破魔（对标弱点+Break）

每个妖魔有**弱点元素**与**魔盾值**：

- 命中弱点元素 → 魔盾 -1（增幅可一击多盾）
- 魔盾归零 → **破魔**：妖魔眩晕一回合、受到伤害大幅加深
- 妖魔的行动规律围绕"逼玩家集火弱点"设计，探查技能（莫凡）可揭示弱点

### 3. 元素即职业（对标职业系统）

- 每个角色固定先天系别（见 characters.md），法术树随等级研习（初级→中级→高级法术）
- **法器/魔具装备**提供跨系副技能（对标副职业，保留构筑自由度）
- **莫凡专属**：雷/火双形态切换（战斗内的 stance 机制，全游戏唯一）

### 4. 战败处理：回到安全网

- 战败读回**最近存档**（状态与剧情进度回到存档时刻）；尚无存档则重开新旅程
- 战败**永不回原地再战**——触发条件随读档解除，战力不足时可绕开、练级后再反打，失败不产生死局

### 战斗流程示意

```
遭遇（暗雷/明雷）→ 转场演出 → 指令轮（选人→选法术→选增幅→结算）
   ↑                                        ↓
   ←—— 胜利：修为/精魄/材料/悬赏进度 ←—— 弱点/破魔循环 ←——
```

## 剧情与演出

- **对话系统**：立绘头像 + 打字机文本 + 选项分支（Godot 可用 Dialogic 插件，或自研轻量版——M1 阶段定）
- **演出**：关键剧情用剧本驱动的 cutscene（镜头移动、对话框、BGM 切换）
- **支线**：NPC 对话接取，完成回目标"完成"，奖励金币/魔具/图鉴；第一章规划 8~12 条

## 成长体系：位阶修炼（仿原著，弃用传统等级）

不设经验值与 LV，成长完全走小说的法师位阶体系（规则详见 [world.md](world.md)）：

```
战斗/悬赏/探索 → 获得修为 → 注入元素系点亮星子（每星级 7 颗）
      ↑                                        ↓
修炼事件（夜间修炼选系）              星级提升：属性+精神力成长
                                               ↓
晋升新阶 ← 晋升仪式 ← 精魄集齐+导师/地点 ← 三星圆满·瓶颈
   ↓
解锁该阶法术研习资格
```

| 系统 | 设计 |
| ---- | ---- |
| 修为获取 | 战斗结算按击杀妖魔的**等级**（奴仆级/战将级……）给予修为；悬赏与探索事件也给 |
| 星子点亮 | 修为注入元素系点亮星子，属性与精神力上限随之成长 |
| 瓶颈与突破 | 三星圆满 → 瓶颈 → 猎杀特定妖魔收集**对应元素精魄** + 晋升地点/导师 → 晋升仪式演出 → 下一阶一星 |
| 修炼事件 | 旅店/宿舍休息时选择**当晚修炼的系**（莫凡在雷/火间分配），额外修为——原著"熬夜修炼"的玩法化 |
| 法术研习 | 晋升新阶解锁该阶法术研习资格，在学院/导师处学习 |
| 精神力 | 战斗施法资源；位阶越高上限越高，高阶法术消耗更大 |
| 装备 | 法杖（主系加成）、魔具（副技能/属性）、护具 |
| 经济 | 金币：悬赏、妖魔材料；去向：装备、旅店、道具、精魄情报 |
| 猎人执照 | 猎者联盟悬赏任务，支线与修为/精魄的重要来源 |

> 突破精魄与妖魔狩猎绑定，天然生成任务：「要突破火系？去猎火系妖魔。」玩家每阶都会主动规划一次狩猎目标。

## 操作与 UI

| 场景 | 操作 |
| ---- | ---- |
| 探索 | WASD/方向键移动，E 交互，Esc 关闭菜单（背包/图鉴待做） |
| 战斗 | **全程键盘可玩**：方向键在指令/法术间导航，回车确认，Esc 返回，W/S 调整星辉增幅；目标选择 ←→ + 回车；鼠标点击为辅助 |
| 菜单 | 篝火菜单：方向键导航 + 回车，Esc 离开 |
| 存档 | 旅店/宿舍存档点 + 随时菜单存档（双保险，M2） |

## 技术落点（Godot 4.7）

- 场景结构：`src/world/`（探索）、`src/battle/`（战斗，独立场景切换）、`src/ui/`
- 遇敌触发：荒野 `Area2D`/步数计数 → 战斗场景 → 带结果返回
- 事件系统：已有的 `GameEvents` 信号总线承载 剧情旗标/任务状态/战斗结果
- 数据驱动：法术、妖魔、道具用 `.tres` 自定义资源（`resources/`）
- 存档：JSON 序列化 GameState + 旗标 + 队伍状态
