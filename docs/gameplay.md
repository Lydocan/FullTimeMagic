# 玩法系统设计（对标《歧路旅人》）

> 状态：v0.1 已确认（回合制方案于 2026-08-31 定案）。

## 表现层：HD-2D

像素角色 + 高分辨率场景 + 现代光影 = 歧路旅人的标志观感。Godot 实现路径：

| 效果 | Godot 4.7 实现 |
| ---- | ---- |
| 像素角色/场景混排 | 角色精灵用像素过滤（Nearest），场景用高分辨率绘制 |
| 景深与视差 | 多层视差背景 + `TileMapLayer` 分层 + Y-sort |
| 氛围光照 | `CanvasModulate` 全局色调 + `PointLight2D`（路灯、法术光效） |
| 泛光/辉光 | `WorldEnvironment` glow（克制使用，夜景与法术才开） |
| 分辨率 | 1920x1080 窗口，像素角色按 3x 整数缩放 |
| 音频 | 占位 chiptune（`Audio` autoload）：4 首 BGM 随场景切换（标题/城镇/林地/战斗），14 个音效（UI/战斗/系统反馈）；正式音频按同名文件替换 |

## 探索层

- **自由移动 + Y 排序**（WASD/方向键，已配好输入映射）
- **交互取舍**：NPC 对话一律**按 E 主动触发**（头顶「!」提示；靠近时的可交互提示只靠**描金光边**，不再浮 E 字样）；场景事件（开场演出、决战台、战后异变）走近自动演出
- **队伍跟随**：入队成员在地图上链式跟随主角（歧路旅人式），无碰撞、不参与遇敌；**入队即满血**（新伙伴不带伤入伙）
- **地图分区（2026-09-05 定案）**：
  - **安全区**：城镇整图安全；野外图中篝火半径（3 格）与子类登记的据点也是安全带，计量在此消退
  - **野外区**：全域可行走格都积累遇敌计量（不再局限于深草），深草 ×1.5 更危险
  - **跨区过场**：安全区↔野外的地图切换各有一段约 5 秒过场——进野外是黑暗中妖兽之眼睁开的压迫演出（准备战斗），回安全区是暖光归来的宁静演出
- **地图名书卷**：界面底部中央以书卷样式显示当前地图名，入场时展开
- **荒野 = 危险区**：
  - **暗雷随机遇敌** + 区域危险度分级（区域越深，妖魔等级越高）
  - **明雷头目**：地图上可见的精英妖魔，打赢给稀有奖励
- **小地图指向牌**：目标本体是脉动金点；另有一枚黄三角骑在面板内切圆的边缘上，始终指向目标方位、随玩家移动沿圆边游动
- **地图技能（Path Actions）**：队伍成员各有一个探索技能（见 characters.md），用于解锁支线、通路、情报——这是歧路旅人探索乐趣的直接移植
- **章节触发**：每章内设若干**剧情触发点**（进入特定区域/完成前置事件后演出）；章节间用世界地图衔接

## 战斗系统（核心，歧路旅人三大支柱的映射）

回合制指令战斗，最多 4 人，按速度决定行动顺序。

### 1. 星辰增幅（对标 BP 增幅）

原著中施法是"星子连线"——游戏中每回合行动者获得 1 点**星辉**（可存至 3 点），出招时消耗星辉增幅：

| 消耗 | 效果 |
| ---- | ---- |
| 0 | 普通施法 |
| 1~3 | 星子连线加长：威力提升 / 攻击段数增加 / 附加效果强化 |

> 主题咬合：增幅在视觉上就是"更多星子连成星轨"，法术演出天然分档。

### 2. 魔盾与破魔（对标弱点+Break）

每个妖魔有**弱点元素**与**魔盾值**：

- 命中弱点元素 → 魔盾 -1（增幅可一击多盾）
- 魔盾归零 → **破魔**：妖魔眩晕一回合、受到伤害大幅加深
- 妖魔的行动规律围绕"逼玩家集火弱点"设计，探查技能（莫凡）可揭示弱点

### 战利品与立绘

- **概率掉落**：每种妖魔有自己的掉落表条目（`drop_id` + `drop_chance`）——鼠潮翻出月露、雷魔狼凝出魔力结晶、狼王偶落复活羽毛；胜利结算掷骰入包并在面板展示
- **战斗立绘**：画面左侧为我方出招者、右侧为敌方行动者的大幅半身立绘，随行动切换滑入（数据驱动：成员表 + `MonsterData.portrait_path`）
- **动作演出**：物理扑击带压身形 + 利爪弧光横扫；施法起手仰身 + 指尖凝聚星辉

### 3. 元素即职业（对标职业系统）

- 每个角色固定先天系别（见 characters.md），法术树随等级研习（初级→中级→高级法术）
- **法器/魔具装备**提供跨系副技能（对标副职业，保留构筑自由度）
- **莫凡专属**：雷/火双形态切换（战斗内的 stance 机制，全游戏唯一）

### 4. 战败处理：回到安全网

- 战败读回**最近存档**（状态与剧情进度回到存档时刻）；尚无存档则重开新旅程
- 战败**永不回原地再战**——触发条件随读档解除，战力不足时可绕开、练级后再反打，失败不产生死局

### 5. 等阶与等级压制（2026-09-05 定案）

- 妖魔按原著等阶划分：**奴仆级 → 战将级 → 统领级 → 君主级**，与玩家位阶（初/中/高/超阶）同尺度；战斗中敌名牌挂牌显示（如「独眼魔狼王·战将级」）
- **同阶妖兽普遍强于人类**（数值上高半档），突出"城墙外是妖魔领地"的严峻
- **跨阶挑战受压制**：有效阶差 = 妖魔等阶 − 队伍最高位阶——阶差 ≥1 时妖魔伤害 ×(1+0.45/阶)、对妖魔伤害 ×(1−0.25/阶)（下限五折），登场亮红色「等级压制」大章。初阶硬闯战将级妖兽基本必败
- **可攻略保底**：压制系数按个体打折——0 = 人类对手（决斗技能对等）、0.5 = 虚弱个体（林地的先遣狼王分身）、1.0 = 完整压制（博城之变的妖魔大军）
- **施法呼喊**：施法时喊出技能名（系统 TTS 按角色分配男女声与音高；无中文语音包的环境退化为按角色音高的喊招音，技能名飘字始终存在）

### 6. Boss 双血条

- Boss/关键人物有**两管血**：主血条上方悬一道金色空槽 + 「Ⅱ」角标预告；第一管**打空**的瞬间不死亡——盖章演出（狼王狂化/炎纹觉醒）、**换上第二管满血条**（转猩红）、攻击与防御大幅强化
- 两管都打空才算真正击败；灼烧等持续伤害烧空第一管同样接上第二管
- 狼王 = 280 + 200，宇昂 = 240 + 140；博城之变的强化版 Boss 将沿用该系统

### 战斗流程示意

```
遭遇（暗雷/明雷）→ 转场演出 → 指令轮（选人→选法术→选增幅→结算）
   ↑                                        ↓
   ←—— 胜利：修为/精魄/材料/悬赏进度 ←—— 弱点/破魔循环 ←——
```

### 法术演出（2026-09-05 起，design.md 已定案）

出手必须可读：**每段命中对应一道元素演出**，伤害与演出命中瞬间对齐，妖魔技能同享（狼王咆哮=雷暴、炎爆=火球……威胁感双向成立）。

| 元素 | 演出 | 音效 |
| ---- | ---- | ---- |
| 雷 | 闪电自天顶而降（抖动折线 + 落点爆闪 + 震屏） | spell_thunder |
| 火 | 火球弧线抛射 → 爆裂 + 火星四溅 | spell_fire |
| 冰 | 冰棱自脚下错峰突起 + 碎冰光斑 | spell_ice |
| 其余 | 白刃弧光横掠 | （沿用 hit） |

全体目标错峰 0.1s 依次落下（落雷扫过全体的观感）；星辉增幅 = 同一演出多波次重复，段数即观感密度。

## 剧情与演出

- **对话系统**：立绘头像 + 打字机文本 + 选项分支（Godot 可用 Dialogic 插件，或自研轻量版——M1 阶段定）
- **演出**：关键剧情用剧本驱动的 cutscene（镜头移动、对话框、BGM 切换）
- **支线**：NPC 对话接取，完成回目标"完成"，奖励金币/魔具/图鉴；第一章规划 8~12 条

## 成长体系：位阶修炼（仿原著，弃用传统等级）

不设经验值与 LV，成长完全走小说的法师位阶体系（规则详见 [world.md](world.md)）：

```
战斗/悬赏/探索 → 获得修为 → 注入元素系点亮星子（每星级 7 颗）
      ↑                                        ↓
修炼事件（夜间修炼选系）              星级提升：属性+精神力成长
                                               ↓
晋升新阶 ← 晋升仪式 ← 精魄集齐+导师/地点 ← 三星圆满·瓶颈
   ↓
解锁该阶法术研习资格
```

| 系统 | 设计 |
| ---- | ---- |
| 修为获取 | 战斗结算按击杀妖魔的**等级**（奴仆级/战将级……）给予修为；悬赏与探索事件也给 |
| 星子点亮 | 修为注入元素系点亮星子，属性与精神力上限随之成长 |
| 瓶颈与突破 | 三星圆满 → 瓶颈 → 猎杀特定妖魔收集**对应元素精魄** + 晋升地点/导师 → 晋升仪式演出 → 下一阶一星 |
| 修炼事件 | 旅店/宿舍休息时选择**当晚修炼的系**（莫凡在雷/火间分配），额外修为——原著"熬夜修炼"的玩法化 |
| 衣柜与华丽度 | 初始三套免费套装（骑士/魔法师/剑士，各分帽子/上衣/裤子，全部 0 华丽度）；杂货铺出售 10/50/100/1000 金的衣装，华丽度对应 10/50/100/1000。**衣柜入口在杂货铺与背包（I/Tab）底部**（纯外观，不加属性） |
| 换装可视化 | 换装**真实穿在身上**：地图角色为分层渲染（基础身体 + 槽位精灵层，随行走同步跳动/翻转），衣柜左侧有「穿着预览」小人，键盘焦点移到哪件即实时试穿。莫凡槽位：帽子/上衣/下装；穆宁雪另设「连衣裙」（整件替代上下装外观）与「腿袜」（裙摆下露出小腿）。战斗立绘暂不随衣装 |
| 穆宁雪的衣柜 | 入队后衣柜出现「穆宁雪的衣柜」分页。初始银白常服 + 白丝袜；杂货铺出售夏日吊带/蔚蓝毛衣/海风短裙/牛仔热裤/黑丝袜/夏日泳装/银蝶发饰（10-50 金）、女仆装/星夜礼服（100 金）、甜梦洛丽塔/月夜哥特（1000 金）。华丽度与称号按角色独立结算 |
| 时尚称号 | 华丽度 = 拥有**所有**衣装的华丽度总和（与是否穿着无关）；阶梯对齐战力等阶：布衣级 → 新锐级(10) → 战将级(50) → 统领级(100) → 君主级(1000)，衣柜顶部常显 |
| 法术研习 | 晋升新阶解锁该阶法术研习资格，在学院/导师处学习 |
| 精神力 | 战斗施法资源；位阶越高上限越高，高阶法术消耗更大 |
| 装备 | 法杖（主系加成）、魔具（副技能/属性）、护具 |
| 经济 | 金币：战斗掉落、（悬赏待做）；去向：杂货铺购买消耗品与装备（M2 已实现购买→使用/穿戴闭环） |
| 道具 | 消耗品 .tres 数据驱动（回复生命/精神力、战斗复活）；背包 I/Tab 打开，战斗中走「道具」指令 |
| 装备 | 三槽位（法杖/魔具/护具）纯属性加成；魔具「跨系副技能」留待后续扩展 |
| 猎人执照 | 猎者联盟悬赏任务，支线与修为/精魄的重要来源 |

> 突破精魄与妖魔狩猎绑定，天然生成任务：「要突破火系？去猎火系妖魔。」玩家每阶都会主动规划一次狩猎目标。

## 操作与 UI

| 场景 | 操作 |
| ---- | ---- |
| 探索 | WASD/方向键移动，E 交互，I/Tab 背包（使用道具/穿戴装备），Esc 关闭菜单 |
| 商店 | 杂货商处 E 打开：方向键/WASD 选择商品，回车/E 购买，Esc 离开 |
| 战斗 | **全程键盘可玩**：方向键/WASD 在指令/法术间导航，回车/E 确认，Esc 返回，**Z 循环星辉增幅（0-3）**，「道具」指令可用消耗品；目标选择 ←→/A D + 回车/E；鼠标点击为辅助 |
| 菜单 | 篝火菜单：方向键/WASD 导航 + 回车/E，Esc 离开 |
| 存档 | 旅店/宿舍存档点 + 随时菜单存档（双保险，M2） |

## 技术落点（Godot 4.7）

- 场景结构：`src/world/`（探索）、`src/battle/`（战斗，独立场景切换）、`src/ui/`
- 遇敌触发：荒野 `Area2D`/步数计数 → 战斗场景 → 带结果返回
- 事件系统：已有的 `GameEvents` 信号总线承载 剧情旗标/任务状态/战斗结果
- 数据驱动：法术、妖魔、道具用 `.tres` 自定义资源（`resources/`）
- 存档：JSON 序列化 GameState + 旗标 + 队伍状态
