# 世界观设定：魔法取代科学的世界

> 状态：v0.1。标注「待核对」的细节以原著为准，开发时再查证，不阻塞设计。

## 世界基石

这是一个**与现实平行的现代世界**——历史在某个节点分岔，魔法取代了科学成为文明基石：

- **科技水平**停留在上世纪 90 年代的生活质感：老式城市、电视、报刊；但城市运转靠魔法——光系照明、魔具通讯、悬浮列车与飞行魔具（具体形式待核对）
- **妖魔统治荒野**：人类聚居在**城墙城市**内，城墙之外是妖魔的领地。城市安全感是这个世界最基本的情绪基调，而"城墙被攻破"是最深的恐惧——这正是博城之变的戏剧内核
- **魔法师是职业**：觉醒元素、进入学院、考取执照，法师像医生律师一样是正经职业；自由执业者称为**猎人**，接悬赏猎杀妖魔

## 魔法体系

### 觉醒

- 人在青少年时期于**觉醒典礼**上觉醒先天元素系，绝大多数人**只有一系**
- 主角莫凡觉醒**雷、火双系**——肉眼可见的天才标志，是全游戏角色成长差异的核心
- 觉醒系别由先天决定，无法更改 → 游戏中每个角色固定主系（= 歧路旅人中的"职业"）

### 元素系（游戏中即"职业"）

| 分档 | 系别 | 战斗定位倾向 |
| ---- | ---- | ---- |
| 元素系 | 火、冰（冰属风雷之列？待核对）、雷、风、土、植物 | 输出 / 控场 / 机动 / 防护 |
| 白魔系 | 光、治愈、祝福 | 辅助 / 续航 |
| 黑魔系 | 暗、诅咒、亡灵、空间 | 高风险高回报，世界观中的禁忌 |

> 首章实际登场系别以第一章角色为准：雷、火、冰、风、土 即可撑起全部战斗。

### 法师等级

**初级 → 中级 → 高级 → 超阶 → 禁咒**。等级决定可施展的法术层次；施法在设定中表现为**星子连线 → 星轨 → 星图**。

> 这套"星子连线"设定会直接转化为战斗系统的核心机制：增幅 = 连接更多星子（见 [gameplay.md](gameplay.md) 的「星辰增幅」）。

### 妖魔等级

奴仆级 → 战将级 → 统领级 → 君主级（待核对）。博城之变中攻破城墙的已属战将级以上，足以毁灭小城——等级压制感是战斗演出要做出来的东西。

## 组织与势力

| 势力 | 性质 | 游戏中的作用 |
| ---- | ---- | ---- |
| 判庭 | 官方执法机构，审判黑魔法师 | 剧情仲裁者；唐月背景的悬念来源（待核对） |
| 猎者联盟 | 猎人管理与任务发布 | **支线/悬赏系统**的界面化入口（猎人执照） |
| 魔法学院 | 天澜高中、帝都魔法学院等 | 章节舞台 + 成长节点（研习新法术） |
| 家族 | 博城穆氏、宇氏等 | 前期人际冲突来源（婚约、决斗） |
| 黑教廷 | 邪教组织，红衣主教冷爵等 | **贯穿主线的幕后反派**，每章埋一条线索 |
| 军部 | 城防与对外作战 | 张小侯的后续成长线（远期） |

## 地理与章节对应

```
博城（小城·家乡）──→ 帝都（首都·学院）──→ 世界舞台（远期：古都/埃及/威尼斯）
   第一章                第二章                 第三章+
```

每章一张大地图，章节之间用世界地图节点衔接（歧路旅人式）。

## 博城（第一章舞台）区域规划

- **莫家**：老居民楼，父亲的面馆/生计（待核对），家是情感锚点
- **水兰中学 / 天澜魔法高中**：觉醒典礼、日常校园、决斗事件
- **穆宅**：穆氏家族领地，婚约线与压迫感
- **城中心广场**：商铺、猎者联盟分部（教程性悬赏）
- **城墙与城门**：博城之变的终局战场
- **郊外荒野**（灰雾林地·暂名）：教学遇敌区，鼠潮出没

## 历史大事件年表（游戏内呈现顺序）

1. 莫凡穿越（携带"小泥鳅"吊坠与前世记忆）
2. 觉醒典礼：雷火双系震全场
3. 高中三年（游戏内压缩为第一章前半的日常与修炼）
4. 与宇昂魔法决斗，夺得地圣泉修行资格
5. **博城之变**：妖魔攻城，第一章高潮与终局
6. 远行帝都 → 第二章
