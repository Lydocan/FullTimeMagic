## 一句话概述

以《全职法师》小说主线为剧情蓝本，玩法框架参照《歧路旅人》的 **HD-2D 章节制回合制 RPG**：扮演双系觉醒的莫凡，从博城走向更大的魔法世界。

## 参考基准

| 维度 | 参考来源 | 取用内容 |
| ---- | ---- | ---- |
| 世界观与剧情 | 小说《全职法师》（乱 著） | 主线脉络、人物关系、魔法体系 |
| 玩法与剧情触发 | 《歧路旅人》(Octopath Traveler) | 章节制推进、指令战斗（增幅/破防）、地图技能、支线结构 |
| 美术形象 | 《全职法师》动画/漫画 | 角色人设与妖魔造型（转译为像素风格，不直接搬运） |

## 玩法支柱（所有设计向这三条对齐）

1. **元素即流派** —— 觉醒的元素决定角色的战斗"职业"，克制与破防围绕元素展开
2. **章节即旅程** —— 沿小说主线分章推进，每章一张大地图、一段完整剧情弧
3. **猎人式探索** —— 城镇安全、荒野危险，接悬赏、探妖魔、触发地图技能解锁支线

## 章节规划（对应小说卷/篇）

| 章节 | 对应原著 | 内容 | 状态 |
| ---- | ---- | ---- | ---- |
| 序章 | 穿越与觉醒 | 穿越、双系觉醒教学 | 规划中 |
| 第一章：博城篇 | 高中～博城之变 | 天澜高中、决斗宇昂、博城妖变保卫战 | **垂直切片目标** |
| 第二章：帝都篇 | 帝都魔法学院 | 入学试炼、猎人执照、黑教廷线索 | 远期 |
| 第三章+ | 古都浩劫 / 世界学府赛 / 埃及 | 远期规划，待前两章验证后细化 | 未规划 |

**开发策略：先做"序章 + 第一章"的垂直切片**，把探索→剧情触发→战斗→成长的完整循环跑通，再扩章节。

## 合规注意（重要）

本项目为**同人性质**：《全职法师》小说与动画的著作权分属原作者与版权方。

- 纯自用/免费同人是通常可接受的范围；**若未来考虑上架或商业化，必须重做原创化改名**，人物、地名、组织全部替换
- 美术上参考动画的"气质与人设特征"，但具体形象必须重新绘制为像素风，**不得直接抠图或描图动画素材**
