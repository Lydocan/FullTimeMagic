## 一句话概述

以《全职法师》小说主线为剧情蓝本，玩法框架参照《歧路旅人》的 **HD-2D 章节制回合制 RPG**：扮演双系觉醒的莫凡，从博城走向更大的魔法世界。

## 已定决策（2026-08-31 讨论）

| 决策点 | 结论 |
| ---- | ---- |
| 战斗形态 | **回合制指令战斗**——星辰增幅 + 破魔，完整采用歧路旅人框架 |

| 成长体系 | **位阶制（仿原著）**：初/中/高/超阶 × 一~三星，每系独立修炼，**弃用传统等级与经验值** |

## 玩法支柱（所有设计向这三条对齐）

1. **元素即流派** —— 觉醒的元素决定角色的战斗"职业"，克制与破防围绕元素展开
2. **章节即旅程** —— 沿小说主线分章推进，每章一张大地图、一段完整剧情弧
3. **猎人式探索** —— 城镇安全、荒野危险，接悬赏、探妖魔、触发地图技能解锁支线

- **复用**：剧情事件（旗标驱动可重入）、`start_story_battle`、战斗结算、战败读档
- **新增**：①宇昂 Boss 数据（MonsterData，人形妖魔化，火系中阶，弱点雷——与莫凡镜像对轰，待核对动画设定）；②**出战成员子集**：决斗限定莫凡单人上场（队伍其余成员观战）
- **验收**：
  - [ ] 冒烟：宇昂 Boss 模拟战全胜，回合数落在设计区间（参考：双鼠潮 ≤10 回合）
  - [ ] 实机：`chapter1_half_done` 存档出发 → 约定 → 决斗 → 胜利拿名额；故意战败 → 读档不卡死、可重挑
  - [ ] 决斗中穆宁雪/跟随者不参战、不挡位

### M3.2 地圣泉修行

**剧情**：持名额进入地圣泉（博城内圣地，新小地图：泉眼 + 结界，唐月守门）→ **闭关修行抉择**（莫凡雷/火修为分配——双系成长抉择的玩法化高潮）→ 时间流逝演出 → 穆宁雪在泉边**剧情突破中阶**（无需精魄，角色设定：天才压瓶颈→节点突破）→ 中阶法术研习（新增中阶雷/火法术 .tres ×2）。

- **复用**：地图基类、篝火式菜单（闭关 = 修炼的剧情化）、突破 API、法术数据
- **新增**：①地圣泉地图 + 传送门接入博城；②闭关事件（选系 → 大额修为 → 演出）；③**剧情突破调用**（绕过精魄检查的叙事通道）；④中阶法术内容
- **验收**：
  - [ ] 冒烟：剧情突破后穆宁雪冰系中阶一星、中阶法术可施放；存档往返含突破状态与装备
  - [ ] 实机：决斗胜利 → 入泉 → 选系闭关 → 修为入账 → 穆宁雪突破演出 → 回城可研习中阶法术
  - [ ] 出泉后灰雾林地遇敌强度校验（练级区不因玩家变强而失压）

### M3.3 博城之变（守城终局）

**剧情**：修行完成出泉 → 城墙异变，妖魔攻城（狼王率军，兑现前半黑教廷线索）→ **三波连战**：鼠潮群 → 独眼魔狼群 → 狼王（强化版，二阶段）→ 波间城民撤离演出 + 莫父情感锚点 → 狼王授首 → 宇昂暗子暴露（反转二）→ **第一章·完** → 第二章（帝都）预告。

- **复用**：战斗系统、地图基类（城墙新图）、NPC 演出、音频、经济闭环（**战前准备窗口**：守城前开放杂货铺/篝火，买药换装）
- **新增**：①**连战波次链**（战斗胜利不返回地图、直接接下一场；战败读档回本波次前）；②Boss 二阶段（血量阈值切强化状态）；③城墙地图 + 撤离演出事件
- **验收**：
  - [ ] 冒烟：三波连战链模拟全胜；狼王二阶段状态切换触发
  - [ ] 实机：战前准备（购买补给可见效）→ 三波连战一气呵成 → 终局演出完整
  - [ ] 任意波次战败 → 读档回该波次前，补给保留
  - [ ] **全章通关跑测**：新档 → 序章 → 前半 → M3.1 → M3.2 → M3.3 一路通到「第一章·完」，中途无卡点

> **顺序依据**：world.md 年表「决斗夺得地圣泉资格 → 修行 → 妖变攻城」——三段即剧情时序。
> **通用验收门槛**：每段交付时，现有冒烟/场景冒烟全绿不回归；新增内容带自己的冒烟项；实机路径走通后勾选对应条目。
> **实现顺序建议**：M3.1 → M3.2 → M3.3 逐段交付（Boss 战体量最大先啃，也尽早暴露「出战子集」新系统的坑）。

## 合规注意（重要）

本项目为**同人性质**：《全职法师》小说与动画的著作权分属原作者与版权方。

- 纯自用/免费同人是通常可接受的范围；**若未来考虑上架或商业化，必须重做原创化改名**，人物、地名、组织全部替换
- 美术上参考动画的"气质与人设特征"，但具体形象必须重新绘制为像素风，**不得直接抠图或描图动画素材**
